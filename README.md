# City Tourism and Hotel Occupancy Dynamics

### A Descriptive Analytics Project Using R

## About the Project

This project focuses on understanding tourism and hotel occupancy patterns in three Indian cities: Kolkata, Delhi and Jaipur.

The main aim is to study how tourist arrivals change across different seasons and how these changes relate to hotel occupancy rates and room prices. R programming and R Markdown are used to analyse the data and present the results through tables, statistics and graphs.

## Project Goal

The goal is to understand tourism trends, compare hotel performance and identify useful patterns through data analysis and visualisation.

## Conclusion

Through this project, I learned how to use R for analysing tourism-related data and presenting the results in a meaningful way. The analysis helps compare tourist arrivals, seasonal changes, hotel occupancy and room prices across the three selected cities.

Overall, this project provided practical experience in descriptive analytics, data visualisation and using R Markdown to prepare an analytical report.
