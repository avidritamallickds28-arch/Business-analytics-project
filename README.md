# City Tourism and Hotel Occupancy Dynamics

## Project Overview
This project uses Descriptive Analytics to study tourism
and hotel occupancy patterns in three Indian cities.

## Cities
- Kolkata
- Delhi
- Jaipur

## Objectives
- Analyse tourist arrivals.
- Compare domestic and international tourists.
- Study seasonal tourism patterns.
- Analyse hotel occupancy rates.
- Compare average hotel room prices.

## Tools Used
- R Programming
- RStudio
- R Markdown
- GitHub

## Dataset
15 observations and 11 variables.
The dataset is synthetic and intended for educational use.

## Analysis
- Descriptive statistics
- City-wise analysis
- Seasonal analysis
- Hotel occupancy analysis
- Room price comparison
- Correlation analysis
